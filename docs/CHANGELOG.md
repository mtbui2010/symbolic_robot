# CHANGELOG

## 2026-11-17 (selectable D1 layer drop_search_goal deleted)
* `HOMELOOP_D1_LAYERS` no longer knows `drop_search_goal` (robot_agent `drop_search` key `goal_check`, removed there too): on d5dev (3 arms x 4 cells x 150 tasks) it fired 9 times, changed no outcome and added 2 false successes. `drop_search` stays selectable; `all` / `d3` / `d2` hashes unchanged. Record: `docs/home/bench/d4_layers.md` `## Removed`.

## 2026-11-13 (D1 turns on the failure-class options)
* `robot_agent:sage_s8n_d1` and `robot_agent:sage_s8n_ft_d1` turn on five robot_agent options (all default off there): `search_per_object` (each object has its own `search_total` budget), `place_find` (a Find of a place the robot moves to is dropped), `reopen_on_miss` (a Find that misses right after an Open closes and opens the container once, then looks again), `end_state` (a go goal for the dock is made true, go and Dock, before done), `object_words` (the goal's 'phone' and the plan's 'cell phone' are one object for the goal checks). The pack data they read is a manifest overlay (`find` role, `recovery.reopen_on_miss: [Close, Open]`, `end_state: {places: [dock], action: Dock}`), recorded in the run config as `manifest_overlay` with `assumed: true`; the last two match the simulator's partial-open and `docked()` rules, so read them as an ablation. Declared in `bench/suites/home/planners/d1_options.py` (the adapter file is at its size limit; it got shorter). Other planners are untouched. The simulator, the judge and the scoring are not changed. D1 results made before this date are not comparable.

## 2026-11-13 (D1 retry moves inside the skill)
* `robot_agent:sage_s8n_d1` and `robot_agent:sage_s8n_ft_d1` (2 attempts in total, as before) retry INSIDE the skill: the planner issues one call and sees the last attempt. A repeat no longer uses a call of the budget (`max_calls`, `len(env.calls)`, `n_calls`, the calls reported); its simulated time still counts and no repeat starts once `max_sim_time_s` is used up. Now repeated: move, find (also on `absent`), look, open, close, vlm_check, dock, grasp_check, pose, on every failure code except estop and cancelled. Never repeated: pick, place, put_in, handover, say, announce, ask, wait. The call log and `truth` carry `attempts` / `attempt_codes`; the run config carries `skill_retry`. Other planners (one attempt) are untouched: their episodes are byte-identical to the baseline (`tests/test_home_baseline.py`). Code: `bench/suites/home/retry.py`; the simulator and the judge are not changed. D1 results made before this date are not comparable (their repeats used budget calls and skipped `absent`). A planner's own second look is not touched.

## 2026-11-13 (the household simulator and benchmark move in)
* `homeloop_robot` (the household simulator, frozen at tag `sim-freeze-r19`) is now `symbolic_robot/domains/home/` and `homeloop_bench` (HomeLoop-Bench: data, runner, planners, metrics, tools, recorded history) is now `bench/suites/home/`, both with their git history (tags `home-sim-freeze-r13`, `home-sim-freeze-r19`, `home-bench-<branch>`). Use only this repository from now on; the standalone repositories are not used any more. What moved where, the import mapping and the commits of the two sources: [migration_home.md](migration_home.md); their docs are in `docs/home/`.
* No behaviour change: the scripted calls of 62 episodes (5 houses x 3 profiles x 2 seeds x 2 languages) and the oracle / naive episodes of three benchmark runs are byte-identical to the standalone packages (`tests/test_home_baseline.py`); all 979 simulator tests and 546 benchmark tests pass here (home tests changed only in paths, one in strictness: `test_check_manifest_strict`, see the migration note).
* `python -m bench run --domain home --suite <planners|run|compare|report>` runs the household CLI in process (the subprocess delegation is gone) and passes it every argument; before, `--limit`, `--profile`, `--seeds`, `--tasks` of a home run were consumed by the generic parser and never reached the household CLI. `--split test` is still refused at the front end.
* Rules changed with the merge (CLAUDE.md, `tests/test_layering.py`): the household simulator is no longer "frozen outside this repo" but frozen in place (tag `home-sim-freeze-r19`); robot_agent may be imported inside functions of the home planner adapter files; the moved code over the size limits is listed in `tests/size_baseline.json` with its source (31 entries, not reduced by the move).

## 2026-11-12 (benchmark-only cleanup)
